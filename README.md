# 🌻 Sorpresa del 21 de septiembre — Yuliana

Página romántica responsive para compartir por WhatsApp.

## Estructura

- `index.html` — estructura de la página y textos.
- `styles.css` — diseño, responsive y animaciones.
- `script.js` — interacción, partículas, flores flotantes, música y reinicio.
- `musica-romantica.wav` — instrumental original incluido localmente.

## Cómo probarla

Abre `index.html` en el navegador.

Para publicarla:
- GitHub Pages: sube todos los archivos al repositorio.
- Netlify: arrastra la carpeta/proyecto.
- Vercel: importa el repositorio.

No necesita Node.js ni frameworks.

## Diseño de las referencias

La primera referencia inspiró las pequeñas flores amarillas flotantes.
La tercera inspiró el girasol principal: pétalos, centro, hojas y tallo.
La segunda inspiró el ramo que aparece como cierre después del mensaje.

La flor y el ramo están recreados con SVG para que la página sea ligera y no dependa de imágenes externas.

## Nota sobre la música

La música incluida es una pieza instrumental sencilla generada localmente para esta página. Se inicia después de pulsar «Abrir mi sorpresa», respetando la política de reproducción de los navegadores.
